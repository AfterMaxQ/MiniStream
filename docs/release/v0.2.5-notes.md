# MiniStream v0.2.5 — Streaming and Remote Input Recovery

This prerelease includes the shared Windows/macOS streaming and remote-input fixes from PR #2.

- Send valid codec parameter sets from NVENC and preserve decoder references across repeated configuration packets.
- Recover missing frames with keyframe requests, retain static captures for recovery, and keep large keyframes intact in the paced send queue.
- Correct Metal texture ownership and the Windows MF decoding/shared-texture path; clear stale surfaces on disconnect.
- Refresh device discovery automatically while idle, and correct keyboard, mouse, and gamepad capture/release behavior.
- Re-prime audio from received sequence numbers after silence/loss, bound capture/playback backlogs, avoid stalled full Windows audio queues, respect encrypted packet size limits, and guard stale macOS audio callbacks.
- Replace the obsolete macOS display-capture implementation with ScreenCaptureKit while preserving the existing backend interface.
- Use shared CMake presets, one source version, and versioned package names for both platforms.

## Downloads

- macOS: `MiniStream-0.2.5-macOS-arm64.dmg` and its SHA256 file. Apple Silicon, macOS 15.0 or newer; this is not a universal/Intel build.
- Windows: installer pending a Windows build from the same `v0.2.5` tag. Follow `docs/release/windows-v0.2.5-handoff.md` to build the x64 NSIS package and add it to this Release.

The macOS app is ad-hoc signed. No Developer ID identity or Apple notarization was used.

## Validation scope

The macOS Release build completed with Apple Command Line Tools, Ninja, and Qt 6.11.2. Tests and diagnostic targets were disabled. No unit tests, CTest, UI tests, application smoke test, or hardware/network streaming test was performed, as requested. Compilation and package creation do not establish that the black-screen or remote-control fixes have passed real-device validation. Windows compilation and packaging remain pending.
