# MiniStream v0.1 alpha release checklist

Complete this checklist on clean target builds before tagging a release.

## Build and package

- [ ] Windows Release build completes with the unified Qt shell enabled.
- [ ] Windows installer is named `MiniStream-Setup.exe` and contains the
      unified application, Qt/QML runtime, MSVC runtime, libsodium, and the
      bundled ViGEmBus setup.
- [ ] Windows installer detects an existing `ViGEmBus` service and offers the
      bundled driver install when it is absent.
- [ ] Driver installation follows the normal Windows UAC flow without an
      automatic restart.
- [ ] macOS Release build completes on the target Mac.
- [ ] `MiniStream.dmg` opens and `MiniStream.app` can be dragged to
      `Applications`.
- [ ] Installed applications start without Qt, CMake, SDK, or compiler files
      installed separately.

## Unified role flow

- [ ] Both platforms show the same top-center `Allow control` / `Remote
      control` switch.
- [ ] Controlled mode reports Video, Audio, Input, and Network capability
      states and stays off the LAN until `Allow control` is pressed.
- [ ] Remote mode discovers only actively broadcasting devices and shows
      system type, device name, codec, resolution, frame rate, HDR, and audio
      parameters without overflowing the card.
- [ ] Both peers display the same six-digit pairing code.
- [ ] Streaming starts only after both peers confirm the matching code.
- [ ] A rejected or cancelled pairing returns to the appropriate idle page.
- [ ] F11 enters and leaves fullscreen; Esc exits fullscreen when local input
      mode is active.
- [ ] `Control remote` routes window-local keyboard, mouse, wheel, and an
      available gamepad; `Use this device`, disconnect, role switching, window
      close, and pairing cancellation release every input lease.
- [ ] Windows uses `Ctrl+Alt+R`; macOS uses `Command+Option+R`.

## Stream acceptance

- [ ] 1080p60 H.264 hardware encode/decode path is verified.
- [ ] 1440p60 and 4K60 HEVC profiles negotiate the expected limits.
- [ ] 4K60 HEVC Main10 HDR10 path is verified on the target display.
- [ ] Stereo audio remains stable for the acceptance session.
- [ ] One controller reaches the controlled application and rumble returns to
      the remote device.
- [ ] FEC restores configured loss and an unrecoverable frame triggers one
      bounded IDR request.
- [ ] Adaptive bitrate reacts to queue/loss overload without unbounded queue
      growth.
- [ ] A dropped session reconnects without restarting either application.
- [ ] Authenticated INPUT and CONTROL packets reject tampering and replay.
- [ ] A 60-minute real-game session has no crash, deadlock, or sustained
      memory/latency growth.

## Verification commands

```text
cmake --build <build-dir> --config Release
ctest --test-dir <build-dir> -C Release --output-on-failure
python tools/check_ui_copy.py ui
cpack --config <build-dir>/CPackConfig.cmake -C Release
```

Keep generated installers, SDKs, driver binaries, captures, and benchmark
dumps out of the Git repository. Package contents are checked from the
generated installer or DMG, not from a development checkout.
